# About
## Installation

Install via the NuGet Package Manager

## 🎯 Design Goals

- Allow for API agnostic extensions to integrate with security
- Enable easy integration testing
- Remain persistence-agnostic (no data annotations or ORM attributes)

## 🧪 Testing

- Extensions should be easily testable in isolation
- No external dependencies
